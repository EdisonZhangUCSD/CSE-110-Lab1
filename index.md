## Projects & Code Samples

I'm a LeetCode enthusiast! Here is a code snippet of the popular problem **Two Sum**:

> Below is a sample solution written in Python:

```python
# A simple solution to the Two Sum problem on LeetCode
def two_sum(nums, target):
    seen = {}
    for i, num in enumerate(nums):
        complement = target - num
        if complement in seen:
            return [seen[complement], i]
        seen[num] = i
    return []
```
